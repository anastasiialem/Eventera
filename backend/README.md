# backend/

Заглушка — код додадуть Роль 1 і Роль 3.

- `parser/` — парсер афіш (Concert.ua, Karabas, сайти театрів, Telegram-канали) + AI-витягування полів (Роль 1).
- API (`/api/events`, `/api/subscriptions`, `/api/telegram/link`, …) і Telegram-бот — Роль 3, деплой на Render.

Схема бази даних — `supabase/migrations/` у корені репо.
